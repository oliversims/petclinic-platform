Secrets module
==============

Role: the OpenAI key in Secrets Manager, plus (when install_eso is true)
the IAM role External Secrets Operator uses to read petclinic/* secrets.


What is created now (wave 1)

  - Secrets Manager secret {project}/{env}/openai-api-key
  - Secret version (value from tfvars)


Held for the second apply (install_eso = true)

  - IAM role + policy for ESO
  - Helm release external-secrets

  ClusterSecretStore and ExternalSecret YAML stay in k8s/base/.


How it is used

  RDS credentials live in the rds module, not here.
  After ESO is installed, YAML CRs sync both secrets into Kubernetes.
